# factorio-mega-mech-armor

## Overview

- Introducing a vehicle type - Mega Mech Armor
- Imagine a spidertron but it can fly.
- Having larger equipment grid.
- Having larger variety of weapons.
- Using combat mode for better biter diplomacy.
- This armor can also in theory space travel by its own.

### Limitations

- The mega mech armor has railgun. To make it not destroying itself, railgun friendly firing is completely removed which affects normal railguns as well.
